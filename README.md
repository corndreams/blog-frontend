# 晚风漫记 Blog Frontend

一个基于 **Vue 3 + Vite + TypeScript** 的个人博客前台项目，包含首页、文章、文章详情、随记、归档、留言、评论、关于等页面，并在路由切换后进行访问埋点统计。

本版本是一次较大的 UI 重构版本：在保留原有接口、路由、文案和核心功能的基础上，将博客整体改造为更偏 **纸张感 / 编辑部风格 / 手账日记风格** 的新版界面。

## 相关仓库

- 博客后台（管理端）：https://github.com/corndreams/blog-manage
- 博客后端（服务端）：https://github.com/corndreams/blog-server

## 本次主要更新

### 1. 全站 UI 重构

本次改造对整个博客前台进行了视觉升级：

- 新增温暖纸张风格设计系统
- 使用统一 CSS 变量管理颜色、阴影、边框、字体和暗色模式
- 全站背景从原来的图片背景改为柔和渐变 + 纸张纹理
- 卡片统一改为大圆角、柔和边框、纸张底色和轻阴影
- 标题更多使用 serif 字体，增强博客和阅读氛围
- 保留并优化深色模式体验

### 2. 首页升级

首页改造为更丰富的博客门户：

- 使用 `src/assets/img/home.png` 作为首页主视觉图
- 首页 Hero 改为纸张相框 / 手账卡片风格
- 保留原有欢迎文案、用户信息、访问统计和社交链接
- 文章列表改为新版纸张卡片展示
- 个人资料卡、访问统计、社交链接整体视觉统一

### 3. 文章页面优化

文章相关页面进行了阅读体验优化：

- 文章列表页新增页面头部和纸张筛选工具栏
- 保留分类筛选、标签筛选、重置和分页功能
- 文章详情页优化为沉浸式阅读布局
- 目录 TOC 改为 sticky 纸张侧栏
- 文章正文针对标题、段落、引用、代码块、图片、表格等进行了样式优化
- 文章详情加载后会自动设置浏览器标题为文章标题

### 4. 随记页面升级

随记页是本次改造中最偏手账风格的页面：

- 保留日历 / 列表切换
- 保留按月份加载随记日期、点击日期进入详情
- 左侧日历改为纸张日历卡片
- 有随记的日期会高亮显示
- 右侧随记详情改为横线纸张和日记印章风格
- 移动端自动改为上下布局

### 5. 归档和留言页优化

- 归档页由传统时间轴改为更清晰的月份归档块
- 分类和标签改为纸张 chip / 小卡片样式
- 留言页改造成 guestbook 风格
- 弹幕留言墙视觉改为纸张背景和气泡样式
- 留言表单保留原有提交逻辑

### 6. 评论和关于页统一

- 评论表单改为纸张输入框和圆角按钮
- 评论列表改为便签 / 气泡风格
- 子评论使用虚线缩进层级
- 关于页新增页面 Hero
- 个人简介、MBTI、年度目标等组件统一成新版纸张风格
- 登录页也同步改为新版视觉风格

### 7. SEO 和性能优化

本次也补充了一些基础 SEO 和性能优化：

- `index.html` 新增 description、keywords、author、robots、canonical
- 新增 Open Graph / Twitter Card 分享信息
- 新增 `public/robots.txt`
- 新增 `public/sitemap.xml`
- 路由切换时自动更新 `document.title`
- 文章详情页使用文章标题更新页面标题
- 首页主图增加 `fetchpriority="high"` 和 `decoding="async"`
- 文章封面、社交图标、头像增加懒加载和异步解码
- 访问统计请求失败时不影响页面运行

> 注意：当前项目仍然是 Vue SPA，基础 SEO 已经增强，但如果后续非常重视搜索引擎收录，尤其是文章详情页收录，可以考虑预渲染、SSG 或 Nuxt。

## 本地运行

### 环境要求

- Node：`^20.19.0 || >=22.12.0`
- 包管理器：pnpm

### 安装依赖

```bash
pnpm install
```

### 启动开发服务

```bash
pnpm dev
```

### 构建

```bash
pnpm build
```

### 预览构建产物

```bash
pnpm preview
```

### 代码检查与格式化

```bash
pnpm lint
pnpm format
```

## 后端地址配置

当前请求基地址在 `src/api/http.ts` 中配置：

```ts
baseURL: 'http://localhost:3000'
```
